## Deeper notes

### Excluded by request

**Dialects** — the entire `Dialects/` tree: <https://mlir.llvm.org/docs/Dialects/>.

Around forty of those pages are generated by `mlir-tblgen` from `.td` files at website build time.
They are not markdown in the repository, they change every release, and a pinned copy would be stale
within weeks. For a version that matches the compiler you are actually running:

```bash
mlir-tblgen --gen-dialect-doc \
  -I llvm-project/mlir/include \
  llvm-project/mlir/include/mlir/Dialect/Arith/IR/ArithOps.td
```

A dozen or so dialects also have hand-written prose documentation in the repository — `affine`,
`linalg`, `vector`, `memref`, `gpu`, `spirv`, `llvm`, `transform`, `tosa`, `shape`, `builtin`,
`emitc`, and a few others. Those are excluded here too, since they sit under the same `Dialects/`
heading. Where this collection depends on a concept from one of them, the concept is explained in
that page's notes rather than assumed — the tensor/memref distinction in
[Bufferization](../04-memory-and-lowering/01-bufferization.md), the builtin type catalogue in the
[Language Reference](../01-core-ir/01-language-reference.md), affine maps in the
[polyhedral rationale](../08-rationale/04-simplified-polyhedral-form.md), and structured operations
in the [structured-ops rationale](../08-rationale/05-structured-ops-rationale.md).

**Passes** — <https://mlir.llvm.org/docs/Passes/>. A generated catalogue of every upstream pass.
`mlir-opt --help` on your own build is authoritative for what is actually linked in, and grepping
`mlir/include/mlir/**/Passes.td` gives you descriptions, options and defaults in one place.

**Pattern Search** — <https://mlir.llvm.org/docs/PatternSearch/>. An interactive website tool rather
than a document: type an operation name and it lists the pattern classes that insert, erase or modify
it. The index is built by running the upstream test suite with `--pattern-logging-listener`, a
technique you can apply to your own dialect.

**SPIR-V Dialect to LLVM Dialect conversion manual** —
<https://mlir.llvm.org/docs/SPIRVToLLVMDialectConversion/>. A detailed, operation-by-operation account
of one specific conversion. Worth returning to as a case study if you ever need to write a large
conversion of your own, since it documents the mappings that are *imperfect*, which most conversion
documentation omits.

**Toy Tutorial** (Ch 1–7) — <https://mlir.llvm.org/docs/Tutorials/Toy/>, source in
`mlir/examples/toy/`. To be handled separately. Still the best end-to-end introduction MLIR has.

**Transform Dialect Tutorial** (Ch 0–4, ChH) —
<https://mlir.llvm.org/docs/Tutorials/transform/>. To be handled separately.

### Excluded because out of scope

The `getting_started` section — build instructions, contribution guide, developer guide, testing
guide, glossary, debugging tips, FAQ, open projects — sits outside `docs/`. Two are worth
bookmarking:

- **Glossary**: <https://mlir.llvm.org/getting_started/Glossary/>
- **Testing Guide**: <https://mlir.llvm.org/getting_started/TestingGuide/>

### Also outside this set

Doxygen API reference (<https://mlir.llvm.org/doxygen/>), the Python bindings API reference
(<https://mlir.llvm.org/python-bindings/>), the deprecations page
(<https://mlir.llvm.org/deprecation/>), and the publications and talks listings.

### One note on the `Bindings` and `Tools` landing pages

Both appear in the upstream index as parent entries, but neither has its own markdown in the
repository — they are navigation stubs generated by the website. Their children are all included
here: `Bindings/Python` in [section 07](../07-bindings-and-embedding/README.md), and the three
`Tools/` pages in [section 06](../06-tooling-and-debugging/README.md).
